Shell prompt · Rust · MIT

A fast, opinionated
powerline prompt.

superline understands git and GitHub, spots your Rust, Python, Node and Java projects, and can show your Claude and Codex usage—without ever making you wait for the next prompt.

$ brew install alxhill/superline/superline

The default config, straight after superline install fish.

Fast

A few tens of milliseconds per prompt, git status included.

Lazy

Backends only run when needed: no git cost outside a repo, no Python cost outside a project.

Never blocks

Slow lookups—big repos, PR status, AI usage—refresh in the background and are served from a cache.

Flexible layout

Multiple rows, each with an optional right-aligned side that stays put as you type.

Themeable

Two built-in themes, or point at a JSON file with your own colours and symbols.

Any shell

fish, zsh, bash, PowerShell and nushell, all wired up by superline install.

Git, at a glance

The branch, then modified, untracked and staged counts, then how far you are ahead of or behind the upstream. A detached HEAD shows its short hash and the branch it sits on.

Big working tree? The auto backend picks between git's own CLI (with its untracked cache and fsmonitor) and in-process gitoxide based on the size of the index.

Your pull request, one click away

With the gh CLI installed, the current branch's PR appears as a clickable link, coloured by state—draft, open or merged—with a dot for CI: green for passing, yellow for pending, red for failing.

The lookup runs in the background, so switching branches is never slowed down by the network.

Knows what you're working on

Python virtualenvs and .python-version, .nvmrc, .sdkmanrc, rust-toolchain.toml—and mise configs, marked with their own icon. Each module shows its logo when you're in a project and the version when one is pinned.

What just happened

Long-running commands report how long they took, background jobs are counted, and a failure turns the prompt red with its exit code—without clobbering the output above it.

Keep an eye on your AI budget

The ai_usage widget reads your Claude or Codex subscription through the provider's CLI and shows the five-hour, weekly and Fable windows as numbers, bars, blocks or a compact sparkline. Set a threshold and the whole widget changes colour before you hit a limit.

Make it yours

Pick rainbow or simple, or write a theme file that overrides only the colours and symbols you care about—256-colour codes or named colours both work.

Shape the line

Chevrons, rounded caps, thin angles or nothing at all. Separators, spacers and padding can go anywhere in a row to split it into blocks.

And the rest

OS icon, username, hostname, local IP, memory and swap, battery warnings, cached sudo credentials, the time, and your own text—each one cheap enough to leave on.

Get started

  1. Install a Nerd Font

    superline draws with Nerd Font glyphs. MesloLGS is a good default; point your terminal at it.

  2. Install the binary

    brew install alxhill/superline/superline

    Or cargo binstall superline for a prebuilt binary (macOS, Linux, Windows), or cargo install superline to build from source.

  3. Hook it into your shell

    # or zsh, bash, pwsh, nu
superline install fish

    Reload your shell. The command is safe to run more than once; superline init <shell> prints the snippet instead.

One JSON file

The first run writes a config to ~/.config/superline/config.json. Edits apply on the next prompt—no reload. A config is a theme and a list of rows; each row has a left side and an optional right.

Run superline config to open it in $EDITOR, and see the README for every module and option. 

{
  "theme": "rainbow",
  "rows": [
    {
      "left": [
        { "cwd": { "max_length": 60, "wanted_seg_num": 5 } },
        "git",
        "pr"
      ],
      "right": ["python", "cargo"]
    },
    { "left": ["shell", "cmd"] }
  ]
}
